YOLO 自动标注工具 v2.1 - 发行版使用说明
============================================

一、这是什么
本程序是一个 YOLO 批量自动标注工具（Tkinter 图形界面）：
  - 支持 PyTorch 模型（.pt）和 ONNX 模型（.onnx）
  - 选择模型、图片文件夹、输出文件夹后，自动批量生成 YOLO 格式标签（.txt）
  - 支持置信度、IoU 去重、类别过滤设置，标注过程中可随时停止

二、使用方法
1. 双击运行  YOLO自动标注\YOLO自动标注.exe （首次启动较慢，请耐心等待，属正常现象）
2. 顶部选择模型来源：PT 或 ONNX，并选择对应模型文件（.pt / .onnx）
3. 选择图片文件夹（支持 jpg/jpeg/png/bmp/tif/tiff/webp）
4. 选择输出文件夹（自动创建）
5. 设置置信度等参数，点击【开始标注】
6. 标注完成后，输出文件夹内每个图片对应一个同名 .txt 标签文件
7. 如需中途停止，点击【停止标注】即可（PT/ONNX 均支持）

三、实时进度查看（重要）
点击【开始标注】会自动弹出【运行日志】窗口，全程无黑色命令行窗口：
  - 日志窗口实时滚动显示处理情况：
      PT 模式：每张图显示“已处理 x/N 张”
      ONNX 模式：每张图显示“[x/N] 图片名 -> 检测到数量 | 速度”
  - 主界面底部【进度条】同步显示完成百分比与“标注中 x/N”
  - 完成后日志窗口和主界面日志区会显示“完成！标签文件：N 个 / 用时”
  - 日志窗口可随时手动关闭；再次开始标注时会自动重新弹出

四、源码保护说明
本程序已使用 PyInstaller 打包为 Windows 可执行程序：
  - 程序内不包含任何 .py 源文件，只有编译后的字节码与运行库
  - 常规手段（文本编辑器、资源查看器）无法直接读取源码
  - 运行时也不依赖 Python 环境，目标电脑无需安装 Python

五、运行环境要求
  - 64 位 Windows 10 / 11
  - 无需安装 Python / CUDA（默认 CPU 推理）

六、常见问题
1. 杀毒软件误报/拦截：PyInstaller 打包程序可能被部分杀软误报，
   请将程序目录加入信任区或白名单后使用。
2. 首次启动慢：模型运行库（torch 等）加载需要 10-60 秒，属正常。
3. 标注结果不对：请确认模型是 YOLOv8 系列导出的 .pt / .onnx，
   且图片内容与模型训练类别一致。
4. 需要 GPU 加速：当前发行版为 CPU 版本；如需 GPU 版本请另行说明。

七、验证命令（可选，用于确认程序完整性）
  YOLO自动标注.exe --selftest 结果.txt
    - 正常输出：OK
  YOLO自动标注.exe --infer 模型文件 图片目录 输出目录 pt 结果.txt
    - 正常输出：OK labels=N （N 为检测到的目标数）
