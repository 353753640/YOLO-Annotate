# YOLO 自动标注工具（发行版）

> 本仓库只存放**打包好的发行版**（免安装可执行程序），**不包含源码**。

## 最新版本下载

[下载 v2.1 发行版 ZIP](https://github.com/353753640/YOLO-Annotate/releases/latest/download/YOLO-Annotate-v2.1.zip)

下载后解压，双击 YOLO自动标注\YOLO自动标注.exe 即可运行，无需安装 Python。

## 功能

- 支持 PyTorch（.pt）与 ONNX（.onnx）模型批量自动标注，生成 YOLO 格式标签（.txt）
- 点击【开始标注】自动弹出【运行日志】窗口，**实时显示每张图的标注进度**
- 全程无黑色命令行窗口，主界面进度条同步更新
- 支持置信度、IoU 去重、类别过滤，标注过程中可随时停止
- PyInstaller 打包，目标电脑无需安装 Python / CUDA（CPU 推理）

## 使用方法

1. 解压 ZIP 后双击 YOLO自动标注\YOLO自动标注.exe（首次启动较慢，请耐心等待）
2. 选择模型来源（PT / ONNX）和模型文件
3. 选择图片文件夹、输出文件夹
4. 点击【开始标注】，在弹出的日志窗口实时查看进度
5. 完成后输出文件夹内每个图片对应一个同名 .txt 标签文件

详细说明见 使用说明.txt。

## 环境要求

- 64 位 Windows 10 / 11
- 无需安装 Python、无需显卡
